Quality Standards

SEO Checklist

Essential guidelines for maintaining site quality, visibility, and compliance

Meta & content

  • Canonical: one per page; no cross-canonicals (except /shop variants)
  • Hreflang: en-IN, hi-IN, mr-IN
  • Title: {{H1}} ∣ Let's Read India (≤ 60 chars)
  • Description: benefit + action (110–150 chars)
  • Headings: single H1; descriptive H2s
  • Media alt text: action + context

Structured data (JSON-LD)

  • Organization, Website, BreadcrumbList
  • Product (kits/readers), HowTo (routines), VideoObject
  • FAQPage, Course (training), Event (community), ItemList

Performance & accessibility

  • LCP ≤2.5s (3G), CLS ≤0.1, TBT ≤200ms
  • Images: loading="lazy", srcset, next-gen formats
  • Fonts: system stack + preconnect if webfonts used
  • Contrast ≥4.5:1; visible focus states; labelled controls
